# Serpo Rank

Website for Serpo Rank, an SEO service focused on home cleaning businesses.

## Run locally

Requirements: Node.js 22 or newer and pnpm.

```sh
pnpm install
pnpm run dev
```

The development site is served at `http://127.0.0.1:8080`.

## Build

```sh
pnpm run build
pnpm run preview
```

## Project structure

- `src/routes/` contains the site's routes.
- `src/components/site/` contains shared page sections and navigation.
- `src/styles.css` contains the visual system and responsive styles.
- `public/images/` contains the site's self-hosted, optimized illustrations.
